On macOS (Apple silicon) the libimobiledevice binaries are taken from Homebrew's
bottles. The only change made to them is to their library load paths (so they find
the libraries shipped beside them) and an ad-hoc code signature, which macOS requires
after that change. The code is otherwise unmodified.

Exact download URLs and SHA-256 checksums are pinned in `vendor.lock.json`. The
checksums of the files as shipped are in `SHA256SUMS.json` inside the app's `bin` folder.

### Written offer of source

The source code for the LGPL and GPL components above is available from the URLs in
the table. If you cannot get it there, open an issue on the project's repository and
the maintainers will provide the corresponding source for the version you received,
for at least three years from its release.
